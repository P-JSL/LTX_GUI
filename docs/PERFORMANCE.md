# 복잡도 분석과 실측 계획

## 하한선: O(n) 미만의 전체 영상 처리는 일반적으로 불가능

총 `n`개의 입력 프레임을 읽어서 복원 여부를 판단하고 처리해야 하는 문제에서, 임의의 프레임 하나라도 보지 않으면 그 프레임에 모자이크가 존재하는지 알 수 없습니다. 임의 위치에 대상이 있을 수 있으므로 **최악의 경우 Ω(n) 프레임 관찰**이 필요합니다. 출력 전체 프레임을 기록하는 경우에도 Ω(n) 출력 비용이 발생합니다. 따라서 전체 입력·출력 작업이 일반적인 조건에서 `o(n)`이 된다고 보장할 수 없습니다.

대신 상수항 감소, 불필요한 추론 생략, memory bandwidth 절약, GPU 병목 제거로 실제 시간을 단축할 수 있습니다.

## 독립 GUI 구현의 계산 복잡도

| 작업 | 복잡도 | 설명 |
|---|---:|---|
| 입력 파일 중복 검사 | 평균 O(1) | 정규화 경로 해시셋 |
| 큐의 마지막에 추가 | 분할 상환 O(1) | Python list |
| 임의 인덱스 조회 | O(1) | QAbstractTableModel의 직접 인덱싱 |
| 선택 항목 제거 | O(n) | 순서 유지 배열의 원소 이동 |
| 전체 작업 명령 생성/출력 충돌 검사 | 평균 O(n) | 항목당 한 번 검사 + hash set |
| 영상 파일 탐색 | O(f) | 폴더의 f개 파일 시스템 엔트리 순회 |
| 연속 track의 윈도 개수 | O(1) | 직접 수식 계산 |

## LTX 윈도 계산 (원본 공개 소스 파라미터 참고)

하나의 연속 검출 track에 대해 모델 윈도 `W=121`프레임, hop `H=104`프레임(겹침 감소 모드)이라면, `N > 0`에 대한 최소 윈도 수는

`K = 1 + max(0, ceil((N - W) / H))` 이며 `N <= W`에서 `K = 1`입니다.

`K`개 윈도가 커버하는 마지막 프레임 수는 `W + (K-1)H`입니다. `K`는 이 값이 `N` 이상인 최소 양의 정수이므로 위 식이 성립합니다. 코드에서는 `(N-W+H-1)//H` 정수 나눗셈으로 부동소수점 오차를 제거했습니다.

예를 들어 10,000프레임 연속 track: `W=121, H=88`이면 114개, `H=104`이면 96개입니다. 윈도 호출 횟수가 약 15.8% 감소할 **수는** 있지만, 이것이 최종 영상 처리 시간의 15.8% 개선을 의미하지는 않습니다. 잘못된 윈도 축소는 시간적 연속성·품질을 저하시킬 수 있습니다.

## 최적화 후보 (자체 GPU 엔진 개발 시)

1. 감지 모델에 비대상 장면 skip 전략 적용. 단, 전수 판단 조건에서는 샘플링으로 탐지 정확성을 보장할 수 없습니다.
2. 프레임 디코딩/인코딩과 추론을 bounded queue로 중첩해 장치 유휴 시간을 줄임. 실제 VRAM 여유에 따라 버퍼를 제한합니다.
3. 모델-장치 사이 이동을 줄이고 pinned memory 및 비동기 H2D/D2H 전송. 측정 없이는 항상 빠르다고 단정하지 않습니다.
4. NVIDIA는 CUDA Graph 및 TensorRT / CUDA 커널 fusion, AMD는 ROCm/HIP, 공통 GPU 연산은 Triton을 고려합니다. GPU 아키텍처 지원을 먼저 확인합니다.
5. FP16/BF16/FP8은 실제 지원 GPU 및 수치 정확도 검증 후 선택. 정밀도 절감에 따른 결과 왜곡을 측정해야 합니다.
6. 프레임 창의 중복 계산과 track 할당을 캐시/재활용하되, 검출 오차·카메라 전환·시드에 따른 결과 차이를 회귀 시험합니다.

## 검증 방법

- 원본 Jasna vs 신규 UI+동일 Jasna CLI는 GPU 추론 알고리즘이 동일하므로 본질적인 엔진 시간 개선을 주장하지 않습니다.
- 입력 샘플 최소 1080p 1개, 4K 1개, 모자이크 희소/밀집 2개 등 동일 프레임/코덱/모델/seed 사용.
- GPU 세대, 드라이버, CUDA/ROCm 버전, VRAM, CPU/RAM, LTX 모델 해시, FFmpeg 설정을 기록.
- warmup 후 최소 5회 반복, median/p95, 프레임당 시간, peak VRAM, GPU util, 품질 비교(가능할 경우 ROI SSIM/LPIPS 및 블라인드 평정).
- GPU 및 영상 복원 통합 시험은 이 실행 환경에서 진행하지 못했습니다.
